## 🇨🇳 中文

这个技能从用户已有的成果接着往下做，不推翻重来。它按需准备两类锚点图：一致性锚定图和场景锚点图，用来把画面钉在既有品牌资产上。动手前先做区分——哪些元素必须准确呈现，哪些可以自由创作，避免把该准的拍歪、把能放的拍死。两类锚点按创意缺口来准备：缺口在哪，锚点就补在哪。有了场景锚点图之后，再据此发展出完整的场景设计。全程先看内容归属边界，确认素材能用再用。

- 按需准备场景锚点图，用于发展完整场景设计
- 明确区分「必须准确」与「可以创作」两类元素
- 按创意缺口决定准备哪类锚点，缺什么补什么
- 先核对内容归属边界，素材可用才进入创作

## 🇬🇧 English

This skill continues from the results the user already has instead of starting over. It prepares two kinds of anchor images on demand — consistency anchors and scene anchors — to pin the visuals to existing brand assets. Before any creative work it draws the line between what must be rendered accurately and what is free to create, so the accurate parts aren't distorted and the loose parts aren't frozen. The two anchor types are prepared against the actual creative gap: wherever the gap is, that's what gets anchored. With scene anchors in hand, it then develops a complete scene design. Content-ownership boundaries are checked first, so only cleared material gets used.

### ✨ What it does

- Continues from the user's existing results instead of restarting the work
- Prepares consistency anchor images to pin visuals to existing brand assets
- Prepares scene anchor images that feed a complete scene design
- Clearly separates what must be accurate from what is free to create
- Chooses which anchor type to prepare based on the real creative gap
- Checks content-ownership boundaries first and only uses cleared material
